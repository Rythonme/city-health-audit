## L1 数据源（随仓库分发）

1. 《中国城市统计年鉴》：1999–2018 地级市面板（GitHub 公开汇编版 .dta）+ 2020–2025 卷分表 Excel（公开网盘合集），合并为 302 城 × 2003–2024；
2. WHO Ambient Air Quality Database V6.1（2024 年 1 月更新）。

来源引用、官方链接与 SHA256 见 `data/raw/SOURCE.md`；下载与校验由 `scripts/fetch_data.py` 完成。

## 硬规则

1. 原始个体级数据**只读**，不回写；派生结果写入独立目录，不进入公开仓库。
2. 除 `data/raw/` 两份公开文件外，任何受限数据文件（`*.rds` / `*.parquet` / `*.sav` 及其他 `*.dta`）不得提交；`.gitignore` 与 CI 双重拦截。
3. 不可得指标**登记为「可得性缺口」**，不得静默删除（发布规范四条禁令之一）。当前已登记：地级市疾病结局锚（死亡率/发病率）开放数据不可得。
4. 疾病监测类指标缺 `reporting_coverage` 或 ICD/编码版本者，不纳入年度审计；覆盖率 < 0.80 者不插补、直接标记 `unavailable`。
5. 商业 / 互联网大数据仅作补充层，显式标注代理性质与潜在选择偏倚。
6. 结果发布不对具体社区 / 小区域作污名化标注；公平图谱以「资源配置优先级」表述。

## 数据性质声明

`docs/data/*.js` 与 `data/processed/` 中所有数值均为**真实公开数据的计算结果**，可由 `scripts/fetch_data.py` + `scripts/build_data.py` 一键复现。指数分档为方法演示口径，**不构成对任何城市的官方评价**，也不用于排名。

## 投稿语句模板

见 `docs/PAPER_PLAN.md` 第 4 节（中英文模板）。以下占位须在投稿前替换：

- `<OWNER>`：GitHub 账户 / 组织；
- `<DOI>`：Zenodo 归档 DOI；
- `<TAG>`：投稿对应的代码版本标签（如 `p1-v1.0`）；
- `<NUMBER>`：伦理审查批件号；
- `<URL>` / `<DATE>`：OSF 预注册链接与日期。
