# 方法学说明 / METHODS

> 本文件说明审计框架、统计定义与真实数据口径。当前公开仓库的数据层为**真实公开数据**（见 `data/raw/SOURCE.md`）；疾病结局锚（D1）开放数据不可得，相关检验（第 2–3 节）待 L2 数据接入后执行，本文档先行定义口径。

## 1. 审计对象与真实数据层

- **主数据**：《中国城市统计年鉴》双源面板（302 个地级市 × 2003–2024 年；旧版汇编 .dta 2003–2018 + 2020–2025 卷分表 Excel 提取 2019–2024），21 项透明可复算指标，构成五个维度：D2 经济民生、D3 环境卫生、D4 卫生服务、D5 教育文化、D6 设施保障；
- **独立第二数据源**：WHO Ambient Air Quality Database V6.1，用于年鉴 PM2.5 的跨源一致性审计；
- **结局锚 D1**：预期寿命、婴儿/孕产妇死亡率、重大慢病过早死亡率、甲乙类传染病发病率等——开放数据下地级市不可得，登记为缺口，不做代理填补。

所有衍生指标的计算公式见 `dict/indicator_dictionary.csv`（含原始列名与换算式）。

## 2. 两套可比分数（待 L2 数据执行）

对同一城市 × 年份样本，定义：

```
S_det = agg(D2, D3, D4, D5, D6)        # 决定因素层，D1 不参与
S_mix = (1 - w) * S_det + w * D1       # 复现「结局入分」的现行做法
```

基准取 `w = 0.20`，聚合 `agg` 为等权算术平均；真实分析并行报告几何平均、z-score 与定基极差法标准化，以及四套赋权（等权 / 熵权 / 德尔菲 / CFA 载荷），全部作为敏感性分析。

## 3. 主要终点（待 L2 数据执行）

| 终点 | 定义 |
|---|---|
| **Δr** | `cor(S_mix, D1) − cor(S_det, D1)`，年龄标化后 Pearson/Spearman + Bootstrap CI |
| **ΔRMSE** | `RMSE_cv(S_det → D1[t+1]) − RMSE_cv(S_mix → D1[t+1])`，5 折交叉验证 |
| 虚高效应曲线 | `w` 从 0 到 0.4 扫描，画 Δr(w) 与 ΔRMSE(w) |

**关键逻辑**：同年相关可以被机械抬高，但对**未来/独立**结局的预测价值不能。两者并列构成可证伪判据。

## 4. 效度体系（四类 + 两个专项）

| 类型 | 操作 |
|---|---|
| 效标效度 | Δr、年龄标化相关、与独立结局集的回归、k 折交叉验证（待 L2） |
| 结构效度 | CFA 检验维度结构；与 TUHI / 2018 版做收敛与区分效度比较 |
| 区分效度（已知组） | **东/中/西、试点/非试点（已执行，见 5b 节）**；规模组待补 |
| 预测效度 | S_det 预测 t+1…t+3 年 D1 变化（待 L2） |
| **专项：跨源一致性（当前已执行）** | 年鉴 PM2.5 × WHO 独立测量：拼音匹配、逐年 Pearson r、偏倚、MAPE、散点抽检 |
| **专项：构造稳健性（当前已执行）** | Dirichlet 参照系 + 合理扰动情景 + 熵权/百分位情景 + 转移矩阵 + 方差分解（见第 5 节） |

## 5. 构造不确定性（真实数据，已执行）

当前版本在真实面板上执行两类权重不确定性分析（种子 `20261110`）：

### 5.1 全随机参照系：两层 Dirichlet(1)（5,000 次）

1. **维内**：每维度指标权重 ~ Dirichlet(1)，缺失指标按可用权重归一；
2. **维间**：五维权重 ~ Dirichlet(1)，缺失维度按可用权重归一。

分档始终使用基准分布五分位阈值，因此稳定率只反映权重不确定性。**定位**：Dirichlet(1) 代表「对权重完全无知」的参照系，其结论（仅约 12% 城市-年分档稳定率 ≥0.8；均值稳定率 0.42）与复合指标敏感性分析文献一致（Saisana, Saltelli & Tarantola 2005；OECD/JRC 手册第 7 章），属确证性结果，不作为本项目的新发现宣称。**判定规则：某城分档在 >20% 模拟中变化，不得给出确定性分档结论。**

同时输出**分档转移矩阵**（5×5，行=基准档、列=模拟档，行内和为 1）：对角线即稳定率；真实结果显示中间档（B/C/D）对角线仅 24–31%，极端档（A/E）为 63–67%——五分位边界附近的档位结论最不可靠。

### 5.2 现实场景：围绕基准权重的合理扰动（每水平 500 次）

更有政策解释力的问题是：**权重在发布值附近合理波动时分档稳不稳**。每权重分量乘 (1+U(−m, m)) 后重归一，m ∈ {20%, 50%}：

- ±20% 扰动：均值稳定率 0.69，仅 58.5% 城市-年稳定率 ≥0.8——**仍有约四成城市-年档位不稳固**；
- ±50% 扰动：均值稳定率 0.61，稳定率 ≥0.8 者仅 32.8%。

### 5.3 确定性情景对比（熵权 / 逐年百分位）

在最新可算年截面（2024）上并行计算两套确定性方案并与基准（等权×合并 min–max）比较档位：

| 情景 | 定义 | 与基准档位一致率（302 城） |
|---|---|---|
| 熵权维内 | 维内权重按信息熵确定，维间等权 | **7.0%** |
| 逐年百分位 | 指标逐年秩百分位归一 + 等权 | 10.3% |

加权方案与归一化口径的「合理且常见」的替代选择即可使九成以上城市的档位改变——这是「不发布精确档位」的第二条独立证据。网站城市画像支持逐城查看三种方案下的档位（「换方案看档位」面板）。

## 5b. 已知组效度（真实数据，已执行；无需结局锚）

在每城最新可算年（2024）截面上：

- **东/中/西部**（国家统计局省份代码口径）：总分均值 53.1 / 44.3 / 42.7，东-西 Hedges g=0.64，Kruskal-Wallis p<0.0001。维度梯度符合理论预期：D2 经济 g=0.84 最强、D6 设施 g=0.60，**D3 环境 g=0.26 最弱**（环境污染的区域排序本就不应与经济梯度一致）——指数区分了理论上应被区分的组。
- **健康城市试点 vs 非试点**（首批 38 个国家试点，2016-11 全国爱卫办通知附件；区级/县级试点不在地级市面板，匹配 28 个地级市）：总分 Hedges g=1.45。**解读红线：试点是从国家卫生城市中遴选的，该差异主要是选择效应，不能解读为政策效果**；它仅说明指数对已知组有区分度（区分效度），因果问题留给 P3 的准实验设计。

## 6a. TUHI 发布结果直接审计（v0.6.0，已执行）

**数据**：TUHI 官方网站数据接口快照（`data/raw/tuhi/`，2026-11-10 抓取，来源与核验见 `data/raw/SOURCE.md` 第 4 节）：2020–2025 年 × 大城市组/中小城市组 × 全部参评城市总分（296 城/年；2023 年接口值与官方发布新闻稿逐值核对一致）。

**对齐**：官方说明 TUHI 发布年份 Y 的数据时点大多为 Y−1 年，故主对齐 = Y−1；同年对齐并行报告（均值 Spearman 0.730 vs 0.736，结论不受对齐选择影响）。

**指标与结果**（1,776 个城市-年对，296 城 TUHI 全部匹配入面板）：

| 指标 | 结果 |
|---|---|
| Spearman 秩相关（各 TUHI 年） | 0.689–0.784，均值 **0.736** |
| Pearson 相关 | 0.742–0.807 |
| 档位标签一致率（TUHI 五级 vs CHIA A–E） | 6.8%–30.7% |
| 二次加权 kappa | 0.21–0.58（均值 0.375） |
| 交叉表头部对齐 | TUHI 引领级中 **98.4%** 落入 CHIA A 档 |

**解读**：
1. **收敛效度成立**——两套独立数据源（年鉴 vs TUHI 自有来源）与独立框架的指数排序相关 0.74，说明二者测的是同一个构念；
2. **档位标签高度脆弱**——即便排序收敛 0.74，两套合理构造给出的档位标签一致率仅约两成。绝对分数段（TUHI）与相对五分位（CHIA）定义不同是原因之一，但**头部高度一致、中后段系统性错位**的模式说明：靠近档位边界的城市对构造选择极其敏感，任何在用指数发布「确定性档位」都应同时公布档位不确定性（与第 5 节 Monte Carlo 结论互相印证）；
3. **分歧案例仅作口径呈现**（网站/CSV `tuhi_direct_audit.csv` 列出名次差最大的城市-年，如黑河/朝阳/安康）：这些城市在 TUHI 框架（含健康行为、健康产业等调查类数据）中靠前、在年鉴决定因素框架中靠后，反映两套口径关注点不同——**非对错判定**。

**红线**：TUHI 总分与档位版权归发布方；本仓库仅将其用于测量学审计对照，不以任何形式重构、替代或再分发其指数本身。

## 7. 真实数据管线（`scripts/build_data.py`）

固定种子 `20261110`；输入为 `data/raw/` 两份公开文件（哈希校验）：

1. 双源读入：旧 .dta 面板（2003–2018，过滤省级行与区名）+ 新卷分表 Excel 提取（`extract_new_yearbook.py`，数据年 2019–2024；表定位按文件名关键词、列定位按中文表头+范围标签，重叠年 15 项字段 r=1.000 逐字节吻合）；
2. 21 项指标按 `dict/indicator_dictionary.csv` 的公式透明计算（人均化、千/万人率、参保率、清洁燃料覆盖近似）；
3. 逐年 1%/99% 缩尾 → 方向感知的合并 min–max 归一化（0–100）；
4. 维度得分（维度内 ≥2 项可用才计）→ 合成总分（≥3 维可用才计）→ **逐年截面重标定到 0–100**（当年最高分=100、最低分=0；发布口径为相对分，跨年比较是相对位置变化；合成前原值保留在 `overall_raw`）→ 五分位 A–E 分档（不排名）；
5. 两层 Monte Carlo 分档稳定性（每次抽样同口径重标定后套基准阈值）+ 一阶方差分解（同口径）；
6. 拼音匹配 WHO 数据，逐年跨源一致性审计与散点抽检；
7. 输出 `data/processed/*`、`docs/data/*.js`、`dict/*.csv` 及构建摘要（含全部输出 SHA256）。

## 8. 空间、公平与因果边界

- 市内小区域：BYM2 / 经验贝叶斯平滑处理小计数率值，报告不确定性；
- MAUP：街道 / 区 / 市域三套单元重复计算；
- 公平分解：disparity ratio / slope、RII/SII、集中指数、Dagum Gini；人口构成（教育、收入、户籍、迁移）时变校正，排除绅士化造成的伪改善；
- **红线**：指数是测量工具，不得用指数变动做因果宣称；市级结论只作群体陈述，个体推断须有个体数据或明确多层模型。

## 9. 局限

1. 观察性数据 + 准实验只提供有限因果证据；城市非随机入组、政策叠加与溢出需敏感性分析。
2. 口径断裂（如实登记、不填补，见 `data/raw/SOURCE.md` 断裂登记表）：2019 年起医院类指标由「医院+卫生院」改为「医院」；人口分母随卷在户籍/常住间切换（面板 `pop_scope` 逐行标注）；剧场影剧院、用气人口（2019 起）、工资（2022 起）、公交车辆与绿地面积（2023 起）停刊。更近年份扩展路径见 SOURCE.md。
3. 结局锚缺失：当前所有结论限于决定因素层与构造稳健性，不能评价「健康结局」本身。
4. 拼音匹配存在少量不可判定同名（整键弃用），匹配率约 87%（263/302）。
5. 汇编版年鉴为二手整合，个别指标口径以官方年鉴为准；发现异常请提 issue 附官方页码。
6. **审计对象边界**：当前构造稳健性与已知组检验均基于「在用指数的公开框架参考实现」而非 TUHI 发布数据本身；对 TUHI 发布分数的直接审计（收敛效度、档位偏差分解）是路线图最高优先项。
7. 已知组检验为横截面描述性区分度检验；试点 vs 非试点的差异主要反映遴选的选择效应，不构成任何因果证据。
